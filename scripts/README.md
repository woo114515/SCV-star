# 脚本入口约定

`run_m0.ps1` 已提供 M0 入口，读取 `configs/local/` 内的固定版本和地图配置；它会启动游戏并写入验收产物，`human` 模式会显示真人窗口。具体命令见 [M0 说明](../docs/M0_ACCEPTANCE.md)。录像解码、训练和评测入口尚未实现。

- 脚本保持轻量，核心逻辑放在 `src/scv_star/`，避免训练算法散落在入口中。
- 后续每个入口应明确输入配置、输出目录、退出码、是否启动游戏，以及磁盘／网络副作用。
- 只读诊断和会修改状态的任务分别设计；诊断不得自动安装依赖、更新客户端或下载地图。
- 运行前检查固定版本与配置完整性；模板中的未知值不得被猜测填充。
- Windows 和 Ubuntu 使用相同 Python 业务入口，平台差异留在启动适配层。确需 shell 包装时分别提供说明。

实现入口后再将经过验证的具体命令加入 README 和[开发说明](../docs/DEVELOPMENT.md)，不提前提供虚构训练命令。
