## 优先顺序

2026-10-06 补充采集完成：Kevin 提供的 Spawning Tool 导出保留1,720个TvT候选，其中786个相对既有数据新增（732个解码候选、53个91115暂缓、1个版本身份复核）。来源清单已合入当前主清单，字节去重后当时共2,912个文件；比赛级去重现按用户要求跳过，新增原生重放及训练轨迹验收均未完成。详见[获取记录](M2_DATA_COLLECTION.md#m2-spawning-tool-export)。

先验证目标正式版能被接口控制，再验证 GPU 和录像解码。M0 失败不以旧版运行冒充目标完成；M2 失败不先投入大规模训练。

部署调试、数据处理、训练和评估分别计时。每轮训练默认 2 小时，可累计；这个预算不包含研发和评测，也不承诺达到特定段位。

用户已授权M0、M1、M2小样本验证，以及随后公开录像的总体下载和引擎需求统计，详见[公开数据采集](M2_DATA_COLLECTION.md#m2-public-data)。91115引擎获取按用户要求暂缓，原始录像仍可归档计数。本轮不获取其他引擎、不启动训练；后续根据版本覆盖量选择少数引擎，再验收动作前观测对齐；比赛级去重已按用户要求跳过。已知中国区客户端、游戏路径、双系统、100 GB限制不再重复询问；既有实测见[M0记录](experiments/M0_2026-09-29.md)、[M1记录](experiments/M1_2026-09-30.md)和[M2来源记录](M2_DATA_COLLECTION.md#m2-replay-sources)。
