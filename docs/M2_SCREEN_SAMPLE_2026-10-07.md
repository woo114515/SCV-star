排除自定义玩法后，标准候选剩 143 个组合层，其中抽到 94 层、66 个 API 地图名称；这些层包含 746 个候选，**仅其中 94 个被本轮抽样回放，不能宣称 746 个均通过**。其余 49 层包含 89 个候选，未覆盖。地图名称的语言别名、资源修订尚未归一化；没有做比赛级去重。不能将样本通过比例当作总体通过保证或直接计算简单随机抽样置信区间。行为克隆观测—动作对齐与训练就绪仍未验收。
