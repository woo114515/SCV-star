## 来源与使用条件

通过用户提供的 Kevin 邮件分享链接获取既有 CSV 与 TAR 导出。文件名标注批次为 `2026_06_30`，不代表每场比赛发生在该日，也不代表全部 6,876 条 TvT 目录记录已提供。CSV 的比赛时间字段范围为 2021-01-01 至 2026-06-30。

使用要求：注明 Spawning Tool 来源；最终报告或其他成果完成后向 Kevin 提供副本；不再分发数据，获取请求转交 Kevin。原文见[许可记录](SC2_LICENSE_REQUIREMENTS.md#8-spawning-toolkevin-提供的录像导出)。原始 CSV、TAR、逐场清单、分享链接及解出的录像均留在本地，不上传 GitHub。报告回传仍待最终成果完成，本轮未发送邮件。

## 下载与完整性

| 文件 | 字节数 | 结果 |
| --- | ---: | --- |
| `replays_2026_06_30.csv` | 4,615,331 | 22,810 行，22,810 个不同记录 ID 和文件名 |

先读取各文件的小段内容，验证 CSV 结构和录像头解析，再完成下载。对 TAR 使用服务器明确支持的 Range 分段请求，核对每段范围与长度，并记录完整文件的本地 SHA-256。扫描时 22,810 个录像的 MD5 均与 CSV／TAR 文件名中的 MD5 一致，录像头全部可解析，未发现缺失条目。未将本地计算的 SHA-256 声称为提供方独立发布的校验值。

仅从 TAR 读取普通文件，按内容哈希写出选中录像，不使用包内路径直接解压。非 TvT、非标准人数以及已确认非双人人类对抗的录像不生成独立训练候选副本；原始混合种族 TAR 保留作为来源档案。
